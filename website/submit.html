quick start

First-time setup

01

Install

Clone the repo and install dependencies.

pip install -r requirements.txt
02

Set API Key

Export your provider's API key.

set GEMINI_API_KEY=your_key
03

Run

Execute the evaluation command.

python main.py --evaluate-model ...
